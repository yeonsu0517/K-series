# K-series

**K-water Digital Water Management Software**

K-series는 K-water의 물관리 기술과 운영 노하우를 소프트웨어로 구현한 디지털 물관리 기술 S/W 패키지입니다.

이 저장소는 **K-series 소개를 위한 공개 페이지**입니다.  
소프트웨어 설치파일·소스코드를 배포하는 저장소가 아니며, 실제 배포 및 이용조건은 K-water MyWater의 공식 안내를 따릅니다.

## K-series at a glance

| S/W | 주요 분야 |
|---|---|
| **K-DRUM** | 강우–유출 분석 |
| **K-River** | 1차원 하천 수리해석 |
| **K-Flood** | 2차원 홍수·침수 해석 |
| **K-GW** | 지하수 분석 |
| **K-RSIM** | 저수지 모의 |
| **K-AEP+** | 물관리 분석 지원 |
| **K-HQ** | 수위–유량 관계 및 유량 분석 |
| **K-FIM** | 홍수범람·침수 매핑 |
| **K-VCM** | 물관리 의사결정 지원 |

## Purpose

K-series는 강우·유출, 하천, 홍수, 저수지 등 물관리 전 과정을 보다 효율적으로 분석하고 연계하기 위한 기술 S/W 체계를 지향합니다.
